# 三维参考色域外包络

日期：2026-10-30。负责人：主代理。本机开发，不提交或推送，不修改其他工程与原始图片。

## 用户确认

- sRGB、Display P3、BT.2020参考外包络，每个独立开关，与二维三角形开关独立。
- 共用参考峰值：203nit默认，可选600/1000/10000nit。
- RGB色立方体六面采样的半透明外壳和边线；D65、黑位0，沿用像素点的Lab/CAM16-UCS/ICtCp条件。HDR峰值选择不表示标准SDR设备的实际能力。

## 实现

- 新增ReferenceGamut.swift：三个标准原色矩阵（colour-science计算），每面8×8格，三角化、共用顶点/边，暗端加密。默认每包络386顶点、768三角形。
- 复用PixelColorMath和ColorPoint.scene，包络与像素点共享坐标、视角和显示缩放；显示范围按可见外壳与像素点联合计算。
- UI新增三个独立按钮及参考峰值菜单；峰值切换异步重算，旧峰值网格不显示。半透明表面按深度排序，点云绘于前景便于透壳观察。
- ICtCp允许1e-8nit级端点舍入误差，真实范围外仍排除，避免10000nit白点产生网格孔洞。
- 使用已读取color-science技能和正式K06；只读参考HiGamut的RGB六面剖分，不引入其Python/Three.js运行时，也不改其代码。

## 验证计划

1. pytest驱动真实Swift网格，独立colour-science对照三原色×四峰值的全部顶点坐标。
2. 网格边共享、闭合、朝外法向、Euler特征、非法参数及PQ端点验证；关联像素分布回归。
3. iOS设备和模拟器构建；模拟器实际开关、三空间、峰值及旋转检查。结果写入test15，未执行的不标通过。
