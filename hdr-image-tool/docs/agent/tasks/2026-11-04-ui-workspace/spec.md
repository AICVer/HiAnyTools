# 四页工作台规格

- 用户已确认方案 B；模型 DeepSeek-v4-Pro（deepseek-v4-pro-0813）。
- 基线 main / 1e12a24，分支 ui-workspace/root；协调与本地验收负责人 Codex，SwiftUI 修改稿由 Coze 生成。
- 保留原生 iOS 18+ SwiftUI，仅调整界面与必要的 UI 状态组织，不修改图像算法、参数默认值、信号契约或导出行为。
- 底部四页：查看、调整、分析、导出；共享同一个 ImageModel、当前图片和全部处理/导出参数。
- 查看：大图、HDR/SDR/GainMap 切换、导入入口、简明图片状态；详情折叠；保留双击全屏。
- 调整：可见的紧凑预览（不随工具内容滚出），切换高光增强/3D LUT/GainMap 合成，每次一个工具；明确当前处理状态。
- 分析：直方图/二维色度/三维色域三选一；仅显示选中主图，图层设置折叠；保留关键统计域、参考白、采样说明。切图/切页不串用旧分析结果，图层与视角在切页后保留。
- 导出：先选 HDR/SDR，再展示对应格式与色域；质量/DPI/尺寸/体积等折叠。清楚标明导出表观与生成、分享状态。
- 各页无图时可导入；切页不清空图片、参数、有效生成文件；处理中的按钮禁用沿用现有逻辑。切换导出类型时不把另一类结果当作当前结果。
- 验证：本机 Swift/iOS 构建、适量 pytest、模拟器主要交互；如不能完成真实 XDR/真机验收明确列出。覆盖率按实际测量范围报告，禁止以核心覆盖率替代 SwiftUI UI 验证。
- 不新增依赖、不改 .env，不上传图像或签名资料，不自动部署/提交/推送。
