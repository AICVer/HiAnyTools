负责人：主代理；日期：2026-10-30。本机开发，无Git提交/推送。

用户已选择方案A：只在分析副本的源原色线性RGB中将负值置零，再生成二维/三维共用坐标；正向高光不截断；统计修正采样数，不设置暗部亮度门限，不改变预览和导出。原始SDR/HDR分析源选择维持现有输出分析语义。此前已确认的包络默认10000nit、参考白203nit一并落实，网格几何不重构。

已读取项目context、输出契约、K02/K06和知识库协作流程；沿用diagnosing-bugs/color-science。前置证据test19/test20：真实JPEG解码负值和iOS低质量采样导致截图离群，真机汇总及三坐标已吻合。不存在名为Hi[Func]的iOS可直接复用组件；继续使用系统Core Image/CGColorSpace，pytest以现有colour-science独立验证。

实现计划：
- 在小尺寸分析数据中恢复源线性原色，截断负值，再转回工作BT.2020；仅替换确需修正的采样，保持其他采样及正向HDR数值。
- PixelColorMath及参考包络不做全局负RGB裁切，保护合法P3→BT.2020负分量。
- UI显示修正计数，参考包络默认10000nit。
- pytest先红后绿：源RGB负值、P3原色、高光、alpha，再真实JPEG的iOS采样配置、关联与完整回归；记录覆盖率和双目标构建。

范围文件：Sources/PixelDistribution.swift、Sources/PixelVisualizationView.swift、tests/Probe.swift、tests/test_distribution_clamp.py及相关文档。暂无新增依赖或环境变量。
