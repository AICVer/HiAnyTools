## 首轮实现约定

- iOS 18+，SwiftUI + UIKit HDR 图像视图、Core Image、ImageIO；系统框架优先，无第三方运行时依赖。
- 相册选择请求当前表示；另提供文件导入，供原文件验证。导入仍须核查系统返回文件是否含 GainMap。
- 只处理单张静态图；保留原文件，导出为新的文件，通过系统分享/存储入口保存。
- 预览长边最多 2048 像素；输出默认保留原尺寸，可用 R2 按宽或高等比调整；上限 5000 万像素。暂不加入批量、裁切、相机、视频、AI 模型或账号功能。
- 内部工作域：扩展线性 BT.2020，1.0 对应 203 nit 参考白；PQ 编码输出必须验证此对应关系。
- 高光曲线：线性 Y≤0.5 保持，0.5～1 用 smoothstep 过渡增益；RGB 同乘增益。此为首版工程参数，待样图主观验收调整，不是用户指定的最终画质算法。
- 输入 HDR 保持其内容动态范围；增强滑块只作用于 SDR。默认 203 nit 的 SDR 转换没有高于 203 nit 参考白的额外余量。
- PNG 必须核对 BT.2020/PQ 色彩标识；TIFF 嵌入 PQ 色彩描述。原始 GainMap 在烘焙为 PQ 单图后不要求保留。
- 首轮不保留 GPS 等拍摄元数据；颜色和已应用的方向单独处理。导出成功以文件生成及回读通过为准，不声称已保存进系统照片。
