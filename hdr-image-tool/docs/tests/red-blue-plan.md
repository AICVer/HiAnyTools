## 数值验收依据

- 文件大小上限、指定宽高、源文件保持：用户需求的硬约束，0 字节超限容差。
- 锁定比例：整数栅格舍入允许 1 像素差，不接受静默裁切/变形。
- DPI：PNG/BMP 像素每米整数的量化误差上限约 0.0127 dpi，本次容差 0.03 dpi；JPEG/HEIC 用同一容差核对元数据。
- 质量：固定复杂样本高质量与低质量必须实际重新编码；不将所有图像/质量档位的文件体积严格单调当作编码标准。
- PQ：使用 colour-science 的 ST 2084 独立对照，按最终 16 位量化与色彩转换误差设容差，不以“显示能打开”代替数值校验。
- 测试输出只报告已运行的集合，不用历史 PASS 替代本轮。严重缺陷 P1 阻断继续，P2 一般问题给出明确边界与跟踪；任何崩溃/数据覆盖 P0 阻断。

主观画质与真机亮度不在无手机环境伪造 MOS：用户实际 iPhone 16 样图验收作为独立待验收项，记录机型/iOS/屏幕余量/环境。
