# HDR 输出数值与元数据约定

工作空间为扩展线性 BT.2020，1.0 对应 203 nit。PQ输出为BT.2020或Display P3原色的16位PNG/TIFF；P3在此处指D65原色配PQ，不是普通Display P3的sRGB曲线。PQ可编码分量为0～10000nit；系统解码/色彩变换产生的范围外值按编码边界裁切，界面在工作域检测到显著上限越界时提示，不把这种溢出描述为原文件含非法码值。

PNG附带cICP：BT.2020为`9,16,0,1`，P3-D65为`12,16,0,1`；cLLI由最终量化后重新解码至目标原色的线性像素计算，保存MaxCLL和MaxFALL，单位0.0001nit，采用大端字节序及系统zlib CRC。静态图的MaxCLL为全图maxRGB最大值，MaxFALL为全图maxRGB平均值；零值按标准含义处理，未作百分位去离群过滤。P3输出不会用转到BT.2020后降低的maxRGB代替自身分量峰值。

依据：[W3C PNG 第三版 cLLI](https://www.w3.org/TR/png-3/#11cLLI)、[MovieLabs Common Metadata，MaxCLL/MaxFALL算法](https://movielabs.org/md/md/v2.7/Common_Metadata_v2.7.pdf)。

给内存 CGImage 标记 headroom 并不保证 ImageIO 自动把该标记写入文件；本机已实际观察到这种差别。因此 PNG 显式补标准 cLLI，文件大小限制在补完后再检查；像素压缩数据不因补 chunk 重编码。TIFF 保留 16 位 PQ/ICC 数据，但没有在本项目中发明私有 headroom 标签；外部 TIFF 查看器可能采用自己的默认显示映射，须单独验收。App 内预览通过实际像素峰值标记 headroom，避免该默认值低估高光。

真实样本 `PQ-RGBW.avif` 的独立10位原始码值只有0与1023，ST2084独立参考峰值10000nit；macOS原生工作域观察到约10175nit。转换评测先限定到合法PQ域，保留0.5%的数值容差；这不是把阈值放宽到覆盖异常。首次失败、独立解码与复测记录见第三组红蓝军报告。

这些是文件/数学验证，不是对手机物理亮度的测量。

## 灰度合成与 GainMap 输出

合成始终以导入源图的SDR表观为基图。灰度来源可用当前图或另一张图：在扩展线性BT.2020求Y，裁到0…1，乘来源alpha；另一张图先应用方向、再等比居中裁切至基图。对基图直通RGB同乘`G^gray`并恢复预乘alpha，默认G=600/203，界面范围1…16；这不是物体识别或剪切细节恢复，也不是要求输出全图峰值恰好600nit。恢复源图可撤销；反复应用不累计增益。

GainMap JPEG/HEIC使用系统Core Image的SDR/HDR双表观写出，要求ISO辅助图存在并回读尺寸、色域及HDR。生成RGB GainMap以支持原图SDR/HDR色度差别；编辑器中的灰度合成图是增益控制图，不声称与编码器重新量化的辅助图逐字节相同。SDR基图色域可选Display P3（sRGB曲线）或BT.2020（系统标准曲线）。结果在目标原色下的maxRGB需超过203nit；未超过时系统不会生成辅助图，应用明确报错并提供SDR/PQ替代，不伪造HDR。透明铺白底，质量/尺寸/DPI/体积上限沿用导出参数，固定像素尺寸内搜索质量，不能达标则报错。

## SDR 色域与映射

PNG/JPEG/HEIC可选sRGB、Display P3、Adobe RGB (1998)。等XYZ通过色彩管理转换像素，目标范围外裁切；RGB直通先在源SDR编码空间取码值，再以目标ICC解释，不先压到sRGB。因此直通保留编码值而不保持外观。HDR源的直通指其系统生成的SDR表观，不指原始PQ码值。导出最终8位，尺寸重采样和有损编码可改变码值。

系统BMP输出不保留宽色域ICC，本机ImageIO也拒绝带ICC的标准V5实验文件；本版BMP只开放sRGB，其他空间明确拒绝。实验工具保存在output而未接入生产。该限制不影响PNG/JPEG/HEIC三种色域选择。

## 像素分布

默认当前HDR工作图最长边64采样（最多4096点），透明像素排除，半透明恢复直通色后计算坐标；不受查看HDR/SDR/GainMap模式影响。二维使用CIE1931 xy和CIE1976 u′v′，黑色无定义色度不入图；光谱轨迹来自colour-science的CIE1931 2° CMFs，380…780nm每5nm。sRGB/P3/BT.2020三角形独立开关。

用户选择方案A：分析副本在源原色的扩展线性RGB中将负值置零，再转换到共用线性BT.2020计算二维/三维坐标；正向RGB不设上限，不增加暗部亮度门限。仅替换被修正的采样，显示修正采样数；原图、预览、直方图和导出不变。源空间优先使用HDR输入色彩描述，滤镜结果使用保留的源色彩描述，无描述计算图/灰度沿用已定义的工作域；无法线性化的RGB ICC明确报告不支持分析。P3转到BT.2020后的合法负分量不会全局裁零，参考包络和PixelColorMath原始坐标函数也不裁切。缩采样维持原平台默认，数值验证可显式选择同一缩采样配置，避免以平滑平均掩盖问题。

Lab与CAM16-UCS使用D65、203nit参考白（相对XYZ白Y=1）；Lab可超过100。CAM16观察条件与本地HiGamut一致：LA=100cd/m²、Yb=20、平均环绕、完全适应。ICtCp用BT.2100 PQ绝对亮度，保留标准I/Ct/Cp坐标，未采用HiGamut的JND倍率；LMS越过0～10000nit的点明确排除，不静默压缩为SDR。点颜色取源SDR sRGB表观只为辨识，位置由HDR数值决定。点云不等于设备色域体积，未计算凸包或色域容积。

## 三维参考外包络

sRGB、Display P3、BT.2020三个包络采用D65、黑位0、共用白场峰值，默认10000nit，可选203/600/1000/10000nit；参考白仍为203nit。超过203nit时，sRGB/P3名称指原色几何配合所选HDR亮度范围，不代表标准SDR编码或显示设备能力。参考峰值不会改变图像、增强参数、导出结果或固定的CAM16观察条件。

外包络由线性RGB立方体六面采样产生，每面8×8格，采样步长在暗端加密，共用边/顶点，组成386顶点与768三角形的闭合网格。先按原色矩阵变到共享线性BT.2020，再沿用像素点的Lab/CAM16-UCS/ICtCp变换，不裁去Display P3到BT.2020后的少量负分量，不取点云凸包。仅PQ定义域端点容忍1e-8nit级浮点误差。

外壳半透明、表面按深度排序，散点置于前景方便透壳观察；这是比较显示，不是遮挡模拟或精确色域容积计算。三个开关独立于二维三角形；当前可见包络与像素共同决定显示范围，三轴等比例且共用旋转/缩放。

## SDR 3D LUT与增强前后比较

首版.cube契约固定为sRGB编码码值→线性BT.2020，输入网格R最快、DOMAIN默认0～1，2～65阶，三线性插值；支持UTF-8注释/BOM/TITLE与DOMAIN，拒绝1D、非有限值或数据量不匹配。文件不完整声明信号编码时不能由后缀推断；界面明确显示适用编码。用户指定的17³示例以原始字节本地打包，文件SHA保持一致。

源SDR先经色彩管理到sRGB码值，再按DOMAIN归一化、边界钳制、查表；输出直接作为线性BT.2020，1对应203nit，不再做一次EOTF。采用未标记色彩空间的RGBAf数值纹理显式八角点采样，输出负值与>1值保留；alpha透传。分析再沿用方案A截断源线性负值；预览、SDR导出与分析数据的目标量程分别声明，不能用显示截图反推工作值。新增SDR BT.2020目标采用系统标准BT.2020颜色描述编码，与LUT的线性工作域分开。

LUT仅接受原SDR源图；应用、重新应用均从original产生，不累积。恢复原图仍可重新应用已载入LUT；新图清空LUT状态，灰度GainMap合成单独从original处理，不隐式叠加。预览/直方图/导出使用当前结果。比较分析保留原图与增强结果两组相同位置采样；两组使用当前相同峰值和203nit参考白。凸包按分析revision、峰值与三维空间缓存失效，避免显示旧图的包络。

原图散点、增强散点、原图凸包、增强凸包四按钮独立控制二维和三维；原色参考外壳继续独立。二维分别在xy/u′v′中求单调链凸包；三维分别在当前CAM16-UCS/ICtCp/Lab场景坐标求增量凸包。只使用有效、有限采样点；空/重合/共线/共面显示相应点/线/面，不捏造三维体积。凸包填平凹陷，是最多4096采样点的凸包，不是全图精确非凸色域。
